# PDV-D-D
O PDV Empório D&amp;D é um sistema completo de gestão comercial para pequenos e médios mercados, com controle de vendas, estoque, produtos, caixa, relatórios e usuários. Oferece leitura de código de barras, pagamento fiado (Ainda não tem integração PIX ou CARTÃO, necessário confirmação manual) , com interface intuitiva e acesso em rede local.
